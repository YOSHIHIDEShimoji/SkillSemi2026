# スキルゼミ2026テンプレート

このファイル群はスキルゼミ2026（主にPython）の環境構築の統一を図るための設定などが含まれています。Python向けのパッケージ・プロジェクト管理ツールの `uv` を使用します。

## uv関連のファイルの説明

Windows 11 Education の WSL (Ubuntu 26.04) の下で `uv` により初期環境の設定を行い、生成されたファイルを格納しています（一部手作業による修正を行っています）。各ファイルの詳細は以下の通りになっています。

| ファイル / フォルダ | 役割 |
|---|---|
| `.gitignore` | Gitで管理しないファイルやフォルダを指定します。`.venv/`、`__pycache__/`、C/C++のビルド生成物、Visual Studioの一時ファイルなどを除外します。このファイルは `uv` で自動生成されたファイルに追記をしています。進捗に応じて適宜追記してもらいます。 |
| `.python-version` | このプロジェクトで使用するPythonのバージョンを指定します。このファイルには `3.13` と記載されており、`uv` によりPython 3.13が選択されます。 |
| `pyproject.toml` | Pythonプロジェクトの設定ファイルです。必要なPythonバージョンや、NumPy、SciPy、PyTorchなどの依存パッケージを記録します。 |
| `uv.lock` | `uv` が生成する依存関係の固定ファイルです。各パッケージの具体的なバージョンを記録し、学生間で同じPython環境を再現しやすくします。通常は手作業で編集しません。 |
| `README.md` | 環境の使用方法を記載している説明ファイルです。
| `ss2601-01` | 課題ss2601-01のコード、Readmeを格納するフォルダです。各課題のフォルダ構成については後述を参照してください。

この環境を最初に使う際には

    $ uv sync

を実行して環境を構築します。先頭の`$`はLinuxのプロンプト表記の略記です（以下同様）。コマンド実行時にコピーしないでください。

## 各課題のフォルダ構成について

以下のように各課題ごとにフォルダを作成し、ソースコード、READMEを格納します。**データ、中間生成ファイルは格納しないようにしてください。**（データファイルが混入した場合でもGitで管理されないように設定する方法を別途説明します）

```text
SkillSemi2026/
├── ss2601-01/
│   ├── README.md
│   └── ss2601-01.py
├── ss2601-02/
└── ss2602-01/
```

## Gitへの初回のcommit, pushについて

各研究室で指定されたリポジトリサーバ（GitHubなど）へコードを初回のcommit, pushを行うまでの手順です。

1. 配布された tar.gz を展開してフォルダに移動します。

       $ tar xzf SkillSemi2026.tar.gz
       $ cd SkillSemi2026

1. Gitリポジトリとして初期化します。

       $ git init

1. すべてのファイルをGitの管理対象に追加します。

       $ git add .

1. 最初のコミットを作成します。

       $ git commit -m "Initial commit"

1. 各研究室で指定されたリポジトリサーバ上で、空のリポジトリ SkillSemi2026 を新規作成します。このとき、GitHub側では README.md、.gitignore、Licenseなどを追加せず、空のリポジトリとして作成しておくのが簡単です。

1. GitHubで作成したリポジトリのURLを使って、リモートリポジトリを登録します。
   - SSHを使う場合の例は以下の通りです。

         $ git remote add origin git@github.com:USERNAME/SkillSemi2026.git

   - HTTPSを使う場合の例は以下の通りです。

         $ git remote add origin https://github.com/USERNAME/SkillSemi2026.git

1. リポジトリサーバ側に合わせてブランチ名を変更しますにします(以下はGitHub用に`main`に合わせる場合です)。

       $ gitbranch -M main

1. 最後にGitHubへpushします。

       $ git push -u origin main
